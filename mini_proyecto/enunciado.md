# Conclusiones

El proyecto de la biblioteca representó un reto interesante que me permitió fortalecer mis conocimientos en el uso de Docker Compose y en la creación y gestión de bases de datos con PostgreSQL.

Durante el desarrollo, una de las principales dificultades fue la configuración y ejecución del entorno mediante Docker Compose. En varias ocasiones surgieron problemas de conexión y acceso a los servicios a través de `localhost`, lo que requirió tiempo de análisis y pruebas para identificar las causas y aplicar las correcciones necesarias. Sin embargo, una vez que el entorno quedó funcionando correctamente, el desarrollo de la base de datos y de las consultas resultó mucho más fluido.

Otro aspecto importante fue la etapa de análisis previo. Comprender los requerimientos funcionales antes de comenzar la implementación permitió diseñar de manera adecuada las tablas, relaciones, restricciones e índices necesarios para el sistema. Gracias a esta planificación, fue posible desarrollar la solución de forma más organizada y eficiente.

## Aprendizajes Obtenidos

- Uso de Docker Compose para la creación y administración de contenedores.
- Configuración y despliegue de PostgreSQL dentro de un entorno Dockerizado.
- Diseño de bases de datos relacionales utilizando claves primarias, claves foráneas y restricciones de integridad.
- Creación de consultas SQL para la obtención y análisis de información.
- Importancia de la planificación y el análisis de requisitos antes de iniciar el desarrollo.

## Conclusión

En conclusión, este proyecto permitió poner en práctica conceptos relacionados con PostgreSQL y Docker, además de reforzar habilidades de análisis, diseño de bases de datos y resolución de problemas técnicos. La experiencia adquirida servirá como base para futuros proyectos que requieran entornos contenerizados y sistemas de gestión de bases de datos relacionales.
