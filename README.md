# Mini Proyecto - Biblioteca con PostgreSQL y Docker

## ¿Qué es este proyecto?

Este mini proyecto consiste en una base de datos para una biblioteca, desarrollada en PostgreSQL y desplegada mediante Docker Compose.

Su objetivo es facilitar la creación y administración de la base de datos mediante contenedores, permitiendo una instalación rápida y sencilla.

## Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalados los siguientes programas:

- Docker Desktop
- Visual Studio Code

## Pasos para ejecutar el proyecto

1. Abre Docker Desktop y verifica que se encuentre en ejecución.
2. Clona este repositorio o descarga el archivo `mini_proyecto.zip`.
3. Abre la carpeta del proyecto en Visual Studio Code.
4. Abre una terminal utilizando `Ctrl + Ñ` o desde **Terminal > New Terminal**.
5. Ejecuta el siguiente comando:

```bash
docker-compose up
```

6. Espera a que Docker descargue las imágenes necesarias y levante los contenedores.
7. Una vez finalizado el proceso, la base de datos PostgreSQL estará lista para su uso.

## Tecnologías utilizadas

- PostgreSQL
- Docker
- Docker Compose
- Visual Studio Code
